Ashline is an offline Counter-Strike-style tactical FPS played in the browser against bots: short rounds, a buy menu, and a bomb to plant or defuse on the original Cinder Wharf map. It runs on vendored three.js with no build step and no network.

## Run it

```sh
node serve.ts
```
